🏥 Healthcare Data Analysis – Wellness Hospitals Dashboard
📌 Project Overview

This project focuses on analyzing healthcare data to understand patient trends, hospital performance, and key operational metrics. Using data analytics and visualization techniques, the project converts raw healthcare data into meaningful insights that support better decision-making in a hospital environment.

The final output is an interactive Power BI dashboard that highlights critical healthcare KPIs in a simple and easy-to-understand format.


🎯 Objectives

Analyze patient admission and discharge trends

Understand hospital workload and performance

Identify key metrics such as patient count, treatment types, and outcomes

Present insights clearly for non-technical stakeholders

🛠 Tools & Technologies Used

Power BI – Data modeling, DAX calculations, and dashboard creation

Excel / CSV – Source data (cleaned before visualization)

Data Analytics Concepts – Data cleaning, KPI analysis, trend analysis



📊 Dashboard Features

Interactive filters and slicers

Key Performance Indicators (KPIs) for hospital operations

Patient admission and discharge analysis

Visual trends for better business understanding

User-friendly layout for quick insights
